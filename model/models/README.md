# Model Files

This directory should contain the following model files:

1. SBERT Model Files:
   - `course_sbert_embeddings.pkl` - Pre-computed SBERT embeddings for all courses
   - `sbert_course_ids.pkl` - Mapping of course IDs to their SBERT embeddings

2. TF-IDF Model Files:
   - `tfidf_matrix.pkl` - TF-IDF matrix for all courses
   - `tfidf_vectorizer.pkl` - TF-IDF vectorizer used to create the matrix
   - `tfidf_course_ids.pkl` - Mapping of course IDs to their TF-IDF vectors

3. Two-Tower Model Files:
   - `two_tower.weights.h5` - Trained weights for the two-tower model

These files are generated by running the following scripts:
- `generate_sbert_embeddings.py` - Generates SBERT embeddings
- `generate_tfidf.py` - Generates TF-IDF components
- `train_two_tower.py` - Trains the two-tower model

Note: These files are not tracked in git due to their large size. They should be generated locally using the provided scripts.
